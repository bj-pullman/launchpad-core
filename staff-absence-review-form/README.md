# Staff Absence Review Portal

Authenticated companion Apps Script project for `staff-absence-public-form`. Deploy it as execute-as-owner and district-domain-only. Set `ABSENCE_SUBMISSION_SHEET_ID`, `APPROVER_EMAILS`, and `GLOBAL_APPROVER_EMAILS` as Script Properties. Share the private queue Sheet with the project owner. See `../staff-absence-public-form/SETUP.md` for the complete runbook.
